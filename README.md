# FitLog（筋トレ記録アプリ）

自分専用の筋トレ記録・トレーニング管理 PWA です。ビルド不要の1枚の HTML ファイル（+ manifest / service worker / アイコン）だけで動きます。

## できること

- 日付ごとのトレーニング記録、カレンダー、体重・体脂肪の記録
- 部位選択、種目ごとのデフォルト値、固定メニューの追加
- 「8回×3セット→10回×3セット→12回×3セット→確認→重量アップ」の進捗管理
- グラフ・レポート・自己ベスト表示
- データのバックアップ／復元（JSON）
- スマホのホーム画面に追加してアプリのように使える（PWA・オフライン対応）

データはすべて **ブラウザの localStorage** に保存されます。このリポジトリにはコードのみが公開され、個人のトレーニング記録は含まれません。

## スマホでアプリとして使う

1. このページの GitHub Pages URL をスマホのブラウザで開く
2. iPhone（Safari）: 共有ボタン →「ホーム画面に追加」
3. Android（Chrome）: メニュー →「アプリをインストール」／「ホーム画面に追加」

## 開発について

- ビルドツールなし。`index.html` を直接編集するだけです。
- `manifest.webmanifest` / `sw.js` / `icon-192.png` / `icon-512.png` は PWA として正しくインストールできるようにするための付随ファイルです。
- ローカルでの作業コピーは別フォルダ（`筋トレアプリ/index_10.html`）にあり、変更のたびにこちらへ反映してデプロイします。
